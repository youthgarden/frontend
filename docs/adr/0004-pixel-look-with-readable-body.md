# ADR 0004: 겉모습은 픽셀, 읽는 글은 고딕

- 상태: 적용 (방향 확인받음, 2026-11-20)
- 날짜: 2026-11-20

## 배경

픽셀 키트와 콘셉트 시안은 도트 그림의 분위기를 정한다. 한편 이 서비스의 사용자는 비개발 직무의 취업 준비생과 재직자이고, 가장 오래 머무는 화면은 영문 메일과 계약서를 읽고 답안을 쓰는 시험 화면이다. 픽셀 글꼴은 짧은 글에는 개성을 주지만 긴 글에서는 읽는 속도를 떨어뜨린다.

## 결정

1. **색과 모양은 키트에서 가져온다.** 디자인 토큰(화면 전체가 함께 쓰는 색과 글꼴의 이름표)을 `src/index.css`에 둔다.

| 토큰 | 값 | 출처와 쓰임 |
|---|---|---|
| `ink` | `#2e1c14` | 키트의 윤곽선 색. 글자와 테두리 |
| `paper` | `#fffaf0` | 시안의 크림색 판. 창과 카드의 바탕 |
| `sky` | `#cfeaf8` | 시안의 하늘. 맵 바깥 바탕 |
| `sun` | `#fdd22e` | 원복과 Lv.1 모자의 노랑. 가장 권하는 버튼, 창의 제목 띠 |
| `uniform` | `#2f66b8` | 원복 반바지의 파랑. 정보 안내, 키보드 초점 |
| `hat-1` ~ `hat-6` | 키트 `HAT_LEVELS` | 레벨 표시 |

2. **테두리는 도트 그림처럼 그린다.** 네 변을 그림자로 따로 그려 모서리가 한 칸 비어 보이게 한다(`px-box`). 둥근 모서리와 흐린 그림자는 쓰지 않는다.
3. **글꼴은 둘로 나눈다.**

| 글꼴 | 쓰는 곳 |
|---|---|
| Galmuri11 (픽셀 글꼴, SIL OFL 1.1 라이선스) | 제목, 버튼, 이름표, 레벨, 숫자처럼 한눈에 보는 짧은 글 |
| 시스템 고딕 (Pretendard, Noto Sans KR, 맑은 고딕 순으로 찾는다) | 과제 설명, 제공 자료, AI 대화, 답안, 피드백처럼 문장으로 읽는 글 |

4. **시험 화면은 장식을 줄인다.** 픽셀 테두리는 영역의 바깥 틀과 위쪽 막대에만 쓰고, 읽고 쓰는 영역은 차분하게 둔다.
5. **캐릭터는 키트가 그린 그대로 쓴다.** 로그인 화면, HUD(맵 위에 항상 떠 있는 정보), 시험관 대화, 레벨업 연출에 같은 캐릭터가 나온다.

## 검토한 선택지

| 선택지 | 버린 이유 |
|---|---|
| 모든 글을 픽셀 글꼴로 | 시험 화면의 긴 글을 읽기 어렵다 |
| 키트 미리보기 화면의 글꼴(Jua + Noto Sans KR)을 그대로 | 둥근 손글씨 느낌이라 도트 그림과 결이 다르다. Google Fonts에 접속해야 해서 오프라인이나 사내망에서 글꼴이 빠진다 |
| NES.css 같은 픽셀 UI 라이브러리 | 키트의 색과 맞지 않고 Tailwind 토큰과 따로 논다. 필요한 부품이 열 개 남짓이라 직접 만드는 편이 가볍다 |

## 결과

- Galmuri11은 npm 패키지 `galmuri`로 들여와 함께 배포한다. 외부 글꼴 서버에 의존하지 않는다. 글꼴 파일 두 개가 합쳐 약 670KB다. 쓰는 글자만 남겨 줄이는 작업은 하지 않았다 (확인 필요: 첫 화면 속도에 문제가 되는지).
- Pretendard는 설치돼 있으면 쓰고 없으면 다음 글꼴로 넘어간다. 모든 사용자에게 같은 본문 글꼴을 보이려면 Pretendard도 함께 배포해야 한다. PoC에서는 하지 않았다.
- 공통 부품은 `src/ui/kit/`에 있다. 화면은 이 부품으로 조립하고 색 값을 직접 쓰지 않는다.
- 와이어프레임(Figma)은 접근 권한이 없어 확인하지 못했다. 화면 배치는 기획서의 유저 플로우와 API 명세를 근거로 정했다 (확인 필요: 와이어프레임과 다른 부분).
