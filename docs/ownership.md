# 분담

프론트엔드는 두 사람이 절반씩 나눠 맡는다. 사용자의 흐름을 따라 "배우는 쪽"과 "검증받는 쪽"으로 나눴다. 2026-11-20에 정했다.

경로별 담당은 `.github/CODEOWNERS`에도 같은 내용으로 적혀 있다. 그 파일은 GitHub가 읽어서, 해당 경로를 고친 PR에 담당자를 리뷰어로 자동 지정한다. **이 문서와 그 파일을 함께 고친다.**

## 누가 무엇을 맡는가

| | 배우는 쪽: 들어와서 강의를 듣기까지 | 검증받는 쪽: 시험을 보고 성장하기까지 |
|---|---|---|
| 담당 | 조가을 (`@autumn-scv`) | 김균호 (`@g0rnn`) |
| 화면 | 로그인·회원가입, 맵(광장과 건물 안), 캐릭터, 맵 위의 정보 카드와 첫 입장 안내, 강의 대시보드와 재생 | 시험관 메뉴, 과제 목록과 안내, 시험 화면, 채점 대기, 결과, 지난 결과, 레벨업 연출 |
| 폴더 | `src/game`, `src/ui/auth`, `src/ui/hud`, `src/ui/lecture` | `src/ui/exam`, `src/ui/levelup` |
| API 파일 | `src/api/domains/auth.ts`, `users.ts`, `lectures.ts` | `src/api/domains/tasks.ts`, `attempts.ts` |
| 응답 타입 | `src/api/types/learn.ts` | `src/api/types/exam.ts` |
| REST API | 9개 (명세 2~5절) | 13개 (명세 6~7절) |
| 실시간 통신 | 멀티플레이 WebSocket (명세 8절) | 없음 |
| 지금 있는 코드 | 약 3,300줄 | 약 2,700줄 |

REST API는 검증받는 쪽이 4개 더 많고 시험 화면 하나가 무겁다. 배우는 쪽은 API 수가 적은 대신 WebSocket, 맵, 유튜브 재생기의 시청 구간 측정이 있다.

## 함께 맡는 것

아래는 어느 한쪽의 것이 아니다. 고치기 전에 서로 알리고, PR에는 두 사람이 모두 리뷰어로 지정된다.

| 경로 | 왜 공통인가 |
|---|---|
| `src/api/core`, `src/api/client.ts`, `src/api/query`, `src/api/types/common.ts` | 모든 요청이 지난다 |
| `src/ui/kit`, `src/index.css` | 모든 화면이 쓰는 부품과 색 |
| `src/events.ts` | 맵과 화면이 주고받는 약속 |
| `src/session`, `src/character.ts`, `src/App.tsx` | 로그인 상태, 캐릭터 외형 규칙, 어떤 창이 떠 있는가 |
| `mock/` | 모의 서버. 백엔드가 분야별로 올라오면 각자 자기 분야의 모의 응답을 걷어낸다 |
| `docs/` | 문서 |

## 두 쪽이 만나는 곳

두 쪽이 서로의 코드에 기대는 곳은 둘뿐이다. 이곳을 고칠 때는 상대에게 알린다.

| 만나는 곳 | 방향 | 지금 있는 연결 |
|---|---|---|
| 강의를 다 들어야 그 과제를 볼 수 있다 | 배우는 쪽 → 검증받는 쪽 | 강의 수강률이 바뀌면 과제 목록도 다시 불러온다. `lectures.ts`의 `invalidateLectureProgress`가 과제의 이름표(`taskKeys.all`)까지 낡았다고 표시한다 |
| 시험에 통과하면 맵의 모자 색이 바뀐다 | 검증받는 쪽 → 배우는 쪽 | 결과 화면이 오른 레벨을 알리면 `App.tsx`가 레벨업 연출을 띄우고, 끝나면 `player-level` 이벤트로 맵에 알린다 |

그 밖에 한쪽 화면에서 다른 쪽으로 넘어가는 버튼이 셋 있다.

- 과제 목록의 "강의 들으러 가기", 결과 화면의 "강의 다시 보기": 시험 쪽이 강의 번호를 넘기면 `App.tsx`가 강의 창을 그 강의로 연다
- 강의 수강 완료 뒤 "시험장으로 이동": 강의 창이 맵의 `goto` 이벤트를 보낸다

## 지킬 것

- 자기 분야의 폴더와 파일을 고친다. 상대의 분야를 고쳐야 하면 먼저 알린다.
- 분야별 API 파일끼리는 이름표만 가져다 쓴다. 상대 분야의 API 함수를 부르지 않는다.
- 화면은 `src/api`(입구)에서만 가져다 쓴다.
- 새 분야가 생기면 이 문서의 표와 `.github/CODEOWNERS`에 함께 더한다.

API를 더하는 순서는 [API 모듈 사용법](api-module.md)에 있다.
